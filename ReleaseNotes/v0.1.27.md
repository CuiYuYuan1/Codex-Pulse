更新内容

- 新增胶囊更新提醒：发现新版本时显示更新图标，悬停查看提示，点击展开版本、标题和更新说明。
- 新增“立即更新”和“跳过此版本”；跳过后当前版本不再提醒，发布更高版本时自动恢复提示。

- macOS 与 Windows 运行中每 5 分钟自动检查 GitHub Releases；应用激活、休眠唤醒或网络恢复时会立即补查。
- 更新说明支持 Markdown 清理和长链接压缩，内容较长时在详情卡内滚动，不挤压操作按钮。
- 发布工作流支持版本专属说明文件，自动构建 Windows 安装包、macOS Universal DMG 和 SHA-256 校验文件。
