更新内容

- 新增“事件视界”黑洞宠物，macOS 使用 Metal 与 ScreenCaptureKit、Windows 使用 WebGL 与桌面捕获，应用窗口经过黑洞时会产生实时引力透镜扭曲。
- 黑洞支持旋转、呼吸、亮度和形态变化，保持固定视觉包络；Codex 思考时会从随机位置逐个吸入代码字符。
- Finder 或资源管理器文件拖入黑洞后会呈现吸入反馈，并安全移入废纸篓或回收站。
- 宠物会按今日 Token 用量成长：每 1000 万 Token 放大 10%，最高 10 倍；每日 Token 清零后恢复基础大小。
- 更新猫咪、恐龙、兔子、幽灵、机器人与九尾狐的跨平台动画渲染，补充工作、思考、授权、成功、失败、睡眠、伸展和桌面漫游动作。
- 新增宠物模式实时对话面板，修复 Windows 原生透明窗口高度不足导致正文裁切的问题。
- 修复 Windows 黑洞在白色背景下出现白色外环、睡眠唤醒后透明区域异常，以及移动时短暂带入旧背景的问题。
- 优化 Windows 胶囊思考态对话展开，移除多层玻璃缩放重影和卡顿；任务信息栏在点击前保持原尺寸。
- 补充宠物成长、黑洞透明合成、实时对话和 Windows 原生渲染回归测试。

安装说明

- Windows：下载 CodexPulse-Windows-Setup-0.1.31-x64.exe。
- macOS：下载 CodexPulse-macOS-0.1.31-universal.dmg。
