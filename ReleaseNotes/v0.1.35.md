更新内容

- 新增四款独立的“小圆球”桌面宠物：连续玻璃环、虚线玻璃环、液态波浪和深色仪表盘，可在宠物菜单中分别选择。
- 四款小圆球均支持单击轮播剩余额度、Token、天气、温度和时间，并保持固定位置、固定大小，不受 Token 成长倍率影响。
- 优化小圆球在浅色与复杂桌面背景上的可读性，状态环会按额度与任务状态切换颜色；思考状态下仅外环或液面运动，中心数字保持稳定。
- Token 页面将数字与 `K / M / B` 单位分层显示，扩大主要数值并保持内容在圆球内居中。
- macOS 与 Windows 统一严格圆形点击区域，点击圆球外的透明窗口区域不会误触发内容切换。
- 补充四款样式、Token 单位布局、交互区域、固定成长倍率和跨平台一致性的自动化及视觉回归测试。
