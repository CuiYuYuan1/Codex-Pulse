更新内容

- 扩展 Codex 窗口吸附信息栏：点击可用额度、今日 Token、缓存命中率、成本、重置时间或近 7 日趋势，可在原高度内切换到对应详情，再次点击返回导航。
- 今日 Token、近 7 日与累计 Token 统一从本机全部 Codex session 汇总，覆盖本机使用过的多个账号，并修复账号切换后额度沿用旧账号缓存的问题。
- 新增缓存 Token、未缓存 Token、缓存命中率、今日成本与累计成本统计；成本按当前模型的输入、缓存输入和输出 Token 分项估算，缓存也计入 Token 总量。
- 优化实时数据链路：session 写入后优先更新今日 Token、缓存命中率和成本，全历史统计转为后台校正，避免界面长时间等待。
- “编程 IQ”改为当前模型在 Artificial Analysis 中对应的编程指数；推理档位只用于匹配同一模型的 low、high、xhigh 或 max 版本，不再直接作为能力值显示。
- Codex 全屏时自动将吸附栏切换到顶部居中安全区，并根据窗口宽度自适应；退出全屏后恢复用户原先选择的吸附方向。
- 优化 Windows 吸附窗口跟随：降低采样管道缓冲，使用短预测和快速收敛减少拖动 Codex 窗口时的延迟、阶梯感与卡顿。
- 修复侧边吸附点击无响应、点击详情时极光线闪烁或移位，以及 macOS 极光线只有点击 Codex 后才显示的问题；极光线现在与 Codex 保持正确相对层级，不会越级覆盖其他应用。
- 优化可用额度实时刷新、重置卡展示、连续使用天数、Token 自适应 K/M/B 单位、任务数量提示和浅色玻璃导航背景。
- 补充账号切换、额度新鲜度、本地用量、缓存/成本指标、四向吸附、全屏布局、双向脱离及 macOS/Windows 一致性的自动化回归测试。
