更新内容

- 修复切换 Codex 账号后可用额度继续显示上一个账号的问题：macOS 与 Windows 现在以 Codex Desktop 当前选中账号为准，账号切换会立即隔离旧缓存并重新拉取当前账号额度。
- 兼容新版 Codex `wham/usage` 额度返回结构，支持 `rate_limit.primary_window`、`reset_at`、`limit_window_seconds` 等字段，避免接口字段变化后回退到旧缓存。
- 本地 session 中无账号归属的额度样本不再覆盖当前账号的远端额度，防止旧账号的 1%/99% 等历史值污染新账号。
- Windows 同步补齐账号切换、异步响应和通知事件的作用域校验，避免晚到响应把当前账号额度覆盖回旧值。
- 补充账号切换和额度新鲜度回归测试，覆盖旧账号 99% 使用切到新账号 44% 使用后应显示 56% 剩余的场景。

安装说明

- Windows：下载 CodexPulse-Windows-Setup-0.1.39-x64.exe。
- macOS：下载 CodexPulse-macOS-0.1.39-universal.dmg。
