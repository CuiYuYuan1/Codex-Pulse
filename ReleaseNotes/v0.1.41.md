更新内容

- 修复 `v0.1.40` 中 Pro 额度可能直接显示为空的问题：通用 `codex` 额度现在会被明确保留，不会被 `GPT-5.3-Codex-Spark` 专用额度过滤规则误伤。
- 收窄 Codex-Spark 专用额度过滤范围：只根据当前额度 bucket 的显式 `id` / `name` 判断，不再使用 `planType` 等容易污染通用额度的字段。
- macOS 补齐新版 `wham/usage` 嵌套结构解析，支持 `usage.rate_limit` 与 `usage.rate_limits_by_limit_id`，避免接口结构变化后被识别成无额度。
- Windows 同步修正过滤规则，并补充 macOS / Windows 回归测试，覆盖通用额度保护、嵌套 `wham/usage` 和 Spark 专用额度过滤场景。

安装说明

- Windows：下载 CodexPulse-Windows-Setup-0.1.41-x64.exe。
- macOS：下载 CodexPulse-macOS-0.1.41-universal.dmg。
