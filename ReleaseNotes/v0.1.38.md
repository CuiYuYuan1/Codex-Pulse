更新内容

- 修复可用额度刷新不稳定的问题：macOS 与 Windows 会直接读取 Codex `wham/usage` 返回的最新 `rate_limits`，优先用接口最新值校准本地缓存，避免十几分钟仍停留在旧额度。
- 兼容 Codex 接口返回的 snake_case 字段，修复部分版本下 `resets_at_seconds`、`remaining_percent` 等字段无法被正确解析导致的额度不同步。
- Windows 详情面板与 macOS 统计区对齐，底部改为固定 2×4 指标网格：今日 Token、累计 Token、缓存 Token、未缓存 Token、缓存命中率、成本、累计成本、任务时间。
- 修复 Windows 详情面板仍显示旧版“本机近 7 日 / 在线天数”三项布局的问题，并提高详情面板高度，避免图表和底部统计区域重叠或被挤压。
- 补充额度新鲜度和 macOS/Windows 详情面板一致性回归测试，防止后续发布包再次带入旧资源或旧字段解析逻辑。

安装说明

- Windows：下载 CodexPulse-Windows-Setup-0.1.38-x64.exe。
- macOS：下载 CodexPulse-macOS-0.1.38-universal.dmg。
