更新内容

- 新增应用内更新下载：点击“立即更新”后不再跳转浏览器，直接在更新详情卡片中下载对应平台安装包。
- 新增下载进度条、实时百分比和已下载/总容量显示；下载失败时可直接重新下载。
- 下载完成后按钮自动切换为“重启并更新”，Windows 与 macOS 均可退出、安装并重新打开 CodexPulse。
- Windows 使用 NSIS 安装包静默更新，并保存已下载安装包；应用意外退出后重新打开仍可继续安装。
- macOS 自动挂载 DMG、替换当前应用并重新启动，同时在不可写目录或直接从 DMG 运行时给出明确提示。
- Windows 与 macOS 均使用 GitHub Release 提供的 SHA-256 摘要校验安装包，校验失败不会执行更新。
- 更新下载、待重启、安装失败和跳过版本状态保持在胶囊更新详情内，并补充跨平台交互与构建测试。

安装说明

- Windows：下载 CodexPulse-Windows-Setup-0.1.29-x64.exe。
- macOS：下载 CodexPulse-macOS-0.1.29-universal.dmg；自动更新前请先将应用放入“应用程序”目录。
