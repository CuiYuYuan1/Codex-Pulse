更新内容

- 新增 5 套内置桌面宠物：小恐龙、猫咪、兔子、幽灵和机器人，默认使用小恐龙。
- 每套宠物拥有独立的空闲、思考、停顿与等待授权动作，并针对深色桌面优化可读性。
- 双击胶囊进入宠物模式；空闲时单击可轮换额度、Token、天气与时间，API Key 模式默认显示时间。
- 思考中或等待授权时，单击宠物可从显示屏位置平滑展开当前对话，再次单击自然回收，宠物位置保持固定。
- 任务信息栏支持 Codex 回复的实时流式滚动；单击后由原信息栏向外扩张显示完整对话，不再弹出独立窗口。
- 思考中和等待授权时，账号模式会在宠物显示屏中轮播当前剩余额度；API Key 模式不会显示账号额度。
- Token 数字改为更及时的实时刷新和向上翻页动画，并统一精简为紧凑格式。
- 远端 Token 统计失败时自动回退到本地 session 数据，减少第三方 API 或网络异常时一直显示 0 的情况。
- 优化 macOS 启动时的 CLI 定位和凭据读取，减少重复授权密码及文件访问提示。
- 修复 Windows Token 翻页中线、宠物拖动、信息栏居中、对话展开跳帧及重复面板等问题。
- macOS 与 Windows 的信息岛、宠物交互和对话动画保持一致，并补充跨平台视觉与交互回归测试。

安装说明

- Windows：下载 CodexPulse-Windows-Setup-0.1.28-x64.exe。
- macOS：下载 CodexPulse-macOS-0.1.28-universal.dmg。
